# Django Shopping Cart Deployment

## Live Website

https://adwaitha.pythonanywhere.com

## Technologies Used

- Python
- Django
- Django REST Framework
- SQLite
- PythonAnywhere

## Deployment Steps

1. Created a PythonAnywhere account.
2. Uploaded the Django project.
3. Created and activated a virtual environment.
4. Installed the required dependencies using pip.
5. Configured the WSGI file.
6. Ran database migrations.
7. Reloaded the web application.
8. Verified that the website was successfully deployed.

## Challenges Faced

- Resolved the `DisallowedHost` error by updating `ALLOWED_HOSTS`.
- Configured the WSGI file correctly to connect the project.
- Created a Django superuser for accessing the admin panel.
